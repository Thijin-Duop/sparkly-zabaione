# BridgePath Hackathon Tracks Web App

A responsive front-end website built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — page structure and content
- `style.css` — responsive layout, colors, hover states and animations
- `script.js` — mobile navigation, track detail modal, application form and scroll effects


## Important: application form
The form is a front-end demonstration. It validates the fields and saves entries in the visitor's browser using `localStorage`. It does not send information to an organiser. A real submission system needs a backend or a form service.

## Customise
- Replace `hello@example.com` in `index.html` with the official contact email.
- Update the BridgePath name and copy if your project uses a different name.
- Connect the application form to a backend when one is available.
